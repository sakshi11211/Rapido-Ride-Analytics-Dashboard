# Rapido Ride Analytics Dashboard Using Power BI

## Project Overview
An interactive Power BI dashboard designed to analyze Rapido ride data and understand ride performance.

## Tools Used
- Power BI
- Power Query
- DAX
- Data Visualization

## Key Features
- Total Rides Analysis
- Completed Rides Analysis
- Average Rating
- Ride Type Analysis
- Interactive Slicers
- Ride Performance Dashboard

## Objective
To analyze ride data and generate meaningful business insights using Power BI.
